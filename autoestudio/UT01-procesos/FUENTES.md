# Procedencia y cobertura

## Alcance confirmado por el estudiante

Examen en Windows; preguntas abiertas de unas cuatro o cinco líneas sobre procesos,
hilos, diferencias y ventajas. Práctica similar a YouTube: Java padre → Java hijo
→ comando, con recuperación de salida. Se practican comandos CMD, no Bash ni
aliases de PowerShell. No se ha comunicado fecha, duración ni ponderación.

## Fuentes consultadas

Rutas relativas a la bóveda hermana `DAM2/`:

- `Fuentes/PSP/aula-virtual/UT1/01 - Apuntes del aula - Procesos.md`:
  definiciones, tipos, estados, BCP, planificación, Runtime y ProcessBuilder.
- `Fuentes/PSP/aula-virtual/UT1/02 - Teoría extra - Procesos.md`:
  guion, comparación de hilos, contexto, swapping, comandos y cuestionario.
- `Fuentes/PSP/aula-virtual/UT1/03 - Ejemplos y ejercicios de procesos.md`:
  Psp/Psp2/PspDir/ProcBuild, directorios y lectura de salida.
- `Asignaturas/PSP - Programación de Servicios y Procesos/UT02/PSP - Hilos - Conceptos y estados (aula).md`:
  solo definición de hilo, entorno compartido y tabla comparativa.

Modelo pedagógico: `dam2-2026-27-ad-labs/autoestudio/`. Ejemplos de nivel:
los tres `practicas/Ejercicio_1_*` del repositorio PSP. No se han modificado.

## Qué se ha añadido

| Objetivo | Material |
|---|---|
| Proceso, hilo, diferencias, ventajas | Primeras cuatro preguntas del banco; mapa de memoria interactivo |
| Concurrencia, paralelismo y contexto | Preguntas y comparación de uno/dos núcleos |
| Estados, tipos, BCP, planificación y swapping | Banco conceptual y transiciones interactivas |
| ProcessBuilder, Process, espera y flujos | Preguntas específicas; teoría en cada taller |
| Ping y lectura | Taller 01 |
| Directorios, rutas, comodines | Talleres 02–03 |
| Crear, copiar, mover, renombrar, consultar | Talleres 04–06 |
| Java fuente frente a clase, proceso nieto | Taller 07 |
| Compilar, empaquetar, ejecutar, abortar ante fallo | Taller 08 |
| Reconstruir la cadena | Taller 09 y cuatro simulacros |

Los enunciados, variantes, respuestas modelo y escenas son elaboración añadida.
Las citas literales se distinguen explícitamente. No son preguntas oficiales.
COPY/MOVE/REN/TYPE se incluyen por petición del usuario, no por confirmación de una
lista oficial de examen. Los bloques NOimpartido no se convierten en obligatorios.

No se afirma sustituir UT01 íntegro. Prioridades, planificación garantizada, colas
múltiples, cálculos de espera/retorno, programación distribuida y arquitectura
mantienen su referencia en la fuente completa. No se añaden talleres Thread,
semáforos, monitores, red HTTP ni productor-consumidor.
