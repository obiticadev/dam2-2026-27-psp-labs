# Ejercicios Extra - Programación de Servicios y Procesos

Colección de ejercicios complementarios sobre creación de procesos, ejecución de comandos del sistema operativo y comunicación interprocesos mediante `Runtime` y `ProcessBuilder`.

---

## Proyectos disponibles

| Directorio | Descripción | Tecnologías clave |
| :--- | :--- | :--- |
| [`Ejercicio_Extra_1_Llamada_a_Navegador`](./Ejercicio_Extra_1_Llamada_a_Navegador) | Apertura del navegador pasando una URL como argumento. | `Runtime.getRuntime().exec` |
| [`Ejercicio_Extra_2_Comandos_y_Procesos`](./Ejercicio_Extra_2_Comandos_y_Procesos) | Ejecución de comandos del SO, lectura de streams, variables de entorno y llamada a JAR externo. | `ProcessBuilder`, `Runtime`, `BufferedReader` |

---

## Estructura normalizada

Cada proyecto sigue el estándar del repositorio:
- `src/`: Código fuente Java.
- `bin/`: Archivos `.class` compilados.
- `lib/`: Dependencias y librerías externas.
- `.vscode/settings.json`: Configuración de entorno para VS Code.
